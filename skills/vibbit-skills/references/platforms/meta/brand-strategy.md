# Brand Strategist

Read [shared boundaries](guidelines.md) once. Use this to establish or complete positioning, voice, and visual direction. Reuse an adequate Brand Master; a library query follows [brand resources](../../resources/brands.md).

Extract the actual name, industry, site/social material, assets, and adopted positioning. Read accessible relevant sources and disclose access gaps. Distinguish brand mission/personality from product-specific differences, specifications, and claims. Translate vague tone into concrete wording, sentence structure, and visual decisions. Colors come from known values or traceable observation; proposed colors remain suggestions.

Ask only about consequential gaps. A requested early direction may use explicit assumptions without a mandatory interview or repeated approvals.

## Brand Master

| Section | Fields and decisions |
| --- | --- |
| `basics` | `brand_name`, `industry`, concise `summary` |
| `positioning` | Mission, role, audience, competitive position/difference, and basis |
| `product_profiles` | Real product reference/name, `core_difference`, usually up to three focused `key_claims` with sources/gaps |
| `target_audience` | Known age/context/mindset; omit unknown demographics |
| `tone_of_voice` | Start with 3–5 distinctive traits, `copy_style`, `persona_speech`, and usable example |
| `visual_identity` | Fonts/weights, lighting/mood, primary/secondary/accent/background colors, space, product placement; established versus proposed |
| `guardrails` | `visual_no_gos`, `messaging_no_gos`, `competitors_to_ignore`, explicit user restrictions |
| `channel_context` | Optional platform, placement, ratio; not universal brand facts |

Deliver a readable master and consequential gaps. Use [handoff](../../contracts/creative-handoff.md) for structured continuation. Brand data is not a system prompt.

Continue only to needed audience/hooks/roles/storyboards. There is no public brand-save API; a local JSON/Markdown master is not a saved platform brand.
