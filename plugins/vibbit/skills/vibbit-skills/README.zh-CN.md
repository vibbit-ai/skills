# 标准插件中的 Vibbit Skill

本目录是正式标准 Skill 加数字人、素材与商品选择器适配。使用完整 `vibbit` 插件安装和升级，方法见上两级发行包 README。MCP 为 `https://mcp.vibbit.cn/mcp`，业务凭据与国内／国际站选择继续由原 Skill 客户端管理。

脚本以实际加载的 SKILL.md 目录为准；交互选择见[数字人说明](references/runtime/avatar-picker.md)、[素材说明](references/runtime/material-picker.md)和[商品说明](references/runtime/product-picker.md)。独立 `skills add` 或 `skills update` 不负责安装本组合插件。
