# Video upscaling

There is no public video-upscaling command. Preserve the existing video and requested target resolution, and identify the need for a supported platform entry or API.

Seedance's 1080p/4k generation settings create new video; they do not upscale the original. Do not silently regenerate it. If the user accepts recreation, use [video generation](../generation/video-generation.md) and explain that content may change. Report improved resolution only after an actual upscaling result.
