# Understanding a reference for adaptation

Use this for reference remakes, stylistic borrowing, or reconstruction of audiovisual relationships. Analyze the actual media with available tools. A single borrowed movement needs only the relevant interval; adapting a whole work needs its opening-to-ending structure, not a claim of full viewing from a few frames.

Understand the overall message, attention shifts, information/emotional progression, and ending. Then inspect the behaviors that create them:
- People: speakers/listeners, gaze, reactions, pauses, actions, and camera participation.
- Captions/headlines: exact text, order, grouping, emphasis, and transitions.
- Graphics: entry, activity, hold, updates, exit, position/scale/opacity, and nearby events.
- Shots/B-roll: the triggering words/actions, evidence shown, and return to the main subject.
- Sound: speech, ambience, music, effects, continuity across cuts, and synchronized reveals.

A ranking board that persists across cuts is one changing component. Track its state, insertions, reordering, and highlights instead of treating every frame as an unrelated image.

## Evidence and interpretation

Record source time separately from semantic purpose. “The portrait enlarges at 6.2 seconds when the name is spoken” can become “show the portrait at the new name,” without copying the old timestamp.

Use overview playback, continuous playback/dense frames for motion, and enlarged stills for text as needed. Gaps between sampled frames remain unknown. Exact timing needs the media's time basis. Recognition errors do not prove the speaker misspoke.

[Parsing](../capabilities/analysis/content-url-parsing.md), [breakdown](../capabilities/analysis/video-breakdown.md), and host media tools can provide evidence. Video-breakdown ASR segments are not word boundaries. [Audio transcription](../capabilities/analysis/speech-transcription.md) can return sentence and word timing; verify units, boundaries, and adopted-media correspondence before use. Preserve real video references when movement/camera/rhythm requires them.

Long work may retain an overall explanation, timed observations, evidence locations, and open questions in existing project records or analysis/timeline files. Do not create a competing adopted script.

## Adapt relationships into visible behavior

Use [reference adaptation](../workflows/reference-remake.md) to establish preservation/replacement scope. Track all manifestations of a replaced identity: performance, voice, portrait, B-roll, screens, and animation. Redesign the action for the new subject while preserving its role; a new product needs its own real functional evidence.

Describe states and events for each element: appearance, meaning range, change, and departure. Bind speech-driven relationships through [semantic timing](script-and-timing.md) and track reuse through [production plans](../contracts/production-plan.md).

Link observation → interpreted purpose → new behavior → review evidence. For example, a clutter problem that persists after changing a box can become tasks still piling up after changing an interface. A sorting demonstration must visibly select/rearrange something, not merely display “choose one.” A concluding action must fit the new method.

These are creative interpretations, not performance evidence. Compare the new work at matching semantic events. New voices and languages need not produce identical timestamps; explicit fixed pauses, duration, or frame preservation require a separate feasibility check.
