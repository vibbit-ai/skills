# Platform methods

Load platform methods for platform-specific advertising strategy, scripts, roles, or market adaptation. Generic generation, subtitle removal, resource queries, and task recovery retain their normal routes. Searching TikTok videos is an external-resource query.

- Meta/Facebook/Instagram creative, or explicit use of these seven methods: [Meta methods](meta/index.md).
- TikTok or another platform without a bundled method: state that boundary and use [general creative direction](../creation/creative-direction.md), user facts, and verified platform information.
- Multiple platforms: share confirmed facts/assets while retaining separate briefs, creative decisions, and revisions.

Keep `target_platform`, `method_source`, and `generation_model` distinct. A user may borrow Meta methods for TikTok, but that does not make them official TikTok guidance.

Methods add creative judgment; they are not API task types. Generic goals, evidence, shot purpose, audiovisual relationships, and dependencies can be shared. Platform hypotheses, numerical recipes, safe areas, and style presets retain their source and applicability. Model-specific prompting belongs in model guides. Use [handoff](../contracts/creative-handoff.md) when needed.
