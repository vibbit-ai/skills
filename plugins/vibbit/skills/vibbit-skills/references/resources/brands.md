# Brands

There is no public brand query or save command. Use the user's supplied logo, colors, tone, claims, and brand material. Keep known facts separate from creative assumptions; use neutral treatment when details are missing instead of inventing a brand profile.

Reuse confirmed facts across platforms while applying each platform's relevant method. A platform-specific method is not a universal layout rule. Saving a local brief does not update a platform brand record. See [creative direction](../creation/creative-direction.md) and [handoff](../contracts/creative-handoff.md).
