# Vibbit Skill in the standard plugin

This is the maintained standard Vibbit Skill with avatar, material and product picker adapters. Install and update it as part of the complete `vibbit` plugin; see the distribution README two directories above this file. The MCP is `https://mcp.vibbit.cn/mcp`. Business credentials and China/international account selection remain with the existing Skill client.

Use the actual installed SKILL.md directory for scripts. Interactive selection is documented in the [avatar guide](references/runtime/avatar-picker.md), [material guide](references/runtime/material-picker.md) and [product guide](references/runtime/product-picker.md). Standalone `skills add` or `skills update` does not install this combined plugin.
