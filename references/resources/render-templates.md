# Local render templates

Discover templates from the user's directory, project, attachment, catalog, or supplied URL. This package does not bundle business video templates. Inspect selection metadata first: name, purpose, engine, full-video/clip/overlay role, real preview, ratio, and duration. Load only the selected project's files and dependencies.

An existing project can be used without repackaging it into a catalog. Preserve the chosen template when possible. Resolve excess text, data, or media through supported adaptation; do not silently truncate user content. Instantiate a working copy while preserving the master and its version.

A full-video template can be delivered locally or export a clean body for cloud packaging. A clip may serve as B-roll. An overlay requires verified transparency and a compatible receiving pipeline, or composition inside the same project.

Use the engine's actual parameter interface; Remotion and Hyperframes are not interchangeable. Inspecting a local template needs no Vibbit API key. Record selected version, inputs, and real outputs using the [template contract](../contracts/render-template.md), [engine guide](../engines/index.md), and [artifact contract](../contracts/render-artifact.md).
