# Reference structures

There is no public personal-library query for viral structures. Analyze actual references and preserve their evidence and limitations. A locally named structure or framework is not a server resource ID.

For saving or selecting reusable scripts, use the [creative library](../workflows/creative-library.md) in user-private persistent storage. Pin revisions and retain source evidence and actual observation coverage for new templates extracted from videos. The Agent's filesystem tools maintain this library without inventing a template-library API.

Reuse expressive relationships while grounding the replacement content in real facts. A successful reference does not guarantee future views or conversion. See [reference remake](../workflows/reference-remake.md).
