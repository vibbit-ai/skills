# Ad localization and glossary

- [Ad Localization](#localization)

<a id="localization"></a>

## Ad Localization

Read [shared boundaries](guidelines.md). Use this for a new market's persuasion, culture, purchase concerns, and creative expression. Plain subtitle/language replacement uses [video localization](../../workflows/video-localization.md).

Need the source creative, actual product/page, target country/market, format, and count. Reuse brand, source market, and actual performance context. Clarify a consequential missing target market; label inferred source markets and do not default to the US. Preserve authorized multi-market scope.

<a id="localization-understand-and-verify"></a>

### Understand and verify

Inspect available source video/images/script: opening, problem, benefit, proof, trust cues, and action. Use parsing/breakdown only when needed. Preserve the useful persuasion mechanism while changing market expression. “Winning” or “viral” requires actual user/data evidence; do not invent success explanations. Disclose limited observation.

Reuse real product references/specifications/variants/prices/guarantees/logos/claims. Research only relevant target-market factors: concerns and trust evidence; natural language/context/terminology/units/currency/date format; actual payment/delivery/return/warranty promises; and landing-page consistency when conversion checking is in scope.

Verify changing facts and applicable rules with relevant primary sources, retaining URL, access date, country, and scope. General articles do not establish product-specific or legal claims. Missing evidence calls for conservative wording or `[UNVERIFIED]`, not fictional research. Avoid unrelated compliance checklists.

<a id="localization-transcreate"></a>

### Transcreate

Adapt the persuasion to the main real purchase barrier while preserving product truth. Use [hooks](emotional-hooks.md#emotional-hooks) or [storyboards](storyboarder.md#storyboarder) only to fill actual gaps.

For a longer ad, a possible structure is opening 0–2 seconds, context 2–5, proof 5–12, concern resolution 12–18, and a final 2–3-second CTA. Adapt or omit it to fit the actual duration. Select people, music, settings, and transaction examples for the real context rather than stereotyped symbols.

Full exploration may recommend three creative directions; user format/count takes priority and recommendations do not automatically trigger paid generation. Preserve original audio when requested; check actual supported pronunciation when new speech is needed.

<a id="localization-deliver-and-produce"></a>

### Deliver and produce

Provide:
1. A change table: original → adapted → reason → source or creative assumption.
2. Localized copy/storyboard with numeric seconds, visuals, overlays, exact speech, sound, transitions, and source assets. Optional back-translation helps review without replacing natural local copy.
3. Actual production status, consequential unchecked claims, and remaining steps, with version/source relations in [handoff](../../contracts/creative-handoff.md).

Use the [terminology guide](#localization-glossary) when useful, avoiding unexplained jargon.

Produce only through supported image/product-video/localization capabilities. Exact logos, prices, warranty text, and long captions may need controlled layers in [hybrid production](../../workflows/hybrid-video.md). Check that path before making paid dependent assets. Generative edits are not guaranteed precise text replacement/lip sync, and unexposed negative-prompt/seed fields must not be invented. Label nonfaithful product concepts as concepts.

Inspect real product appearance, text/claims, language, voice, small-preview readability, and verified placement. Script completion is not video review. Bounded testing suggestions can isolate a proof/hook change; they do not imply a campaign was launched or CTR/CPA observed. This package has no ad publishing interface.

<a id="localization-glossary"></a>

## Advertising terminology

Use clear language with general clients. This glossary supports [ad localization](#localization) without requiring specialist jargon.

| Term | Meaning |
| --- | --- |
| Hook | Opening that establishes attention or a meaningful question |
| On-screen text | Designed visible text, separate from spoken captions when appropriate |
| Voiceover / talking to camera | Offscreen narration / visible direct address |
| Edit sheet | Shot and assembly plan |
| Insert shot / B-roll | Supporting footage |
| Carrying performance | Material contributing materially to measured campaign results |
| Reference image / image-to-image | An input picture / generation guided by an input picture |
| Cross-border expansion | Entering another market |
| Competitor teardown | Evidence-based analysis of competing content |
| Transcreation | Adapting meaning and persuasion for a new audience |
| Feed | Scrolling content surface |
| Carousel | A sequence of separate ad/content cards |
| Badge | Compact visual label |
| Reference / struck-through price | A comparison price requiring a valid factual basis |
| Creator / influencer | A person producing content or influencing an audience |
| Scaling volume | Increasing production or distribution within the agreed scope |
| Placement | The specific surface where the ad appears |
| Back-translation | Translating adapted copy back for meaning review |
| Control | The comparison condition in a test |
| Concept mock | Illustrative design, not a claim of exact product fidelity |
| [UNVERIFIED] | A material claim that has not been verified |
