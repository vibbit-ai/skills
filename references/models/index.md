# Model guides

Read a model guide only when model-specific decisions matter. Preserve an explicit user choice; do not infer cost, speed, or quality from a model name. The public entry's accepted fields may be narrower than a model family's general capabilities. Defaults and request limits belong to the linked API contract.

- [GPT Image](gpt-image.md): image models and shared input shape.
- [Seedance 2.0](seedance-2.0.md): compatibility, modes, and limits.
- [Seedance 2.5](seedance-2.5/overview.md): prompting, reference roles, frames, editing, and extension.

General creative guidance belongs to [image generation](../capabilities/generation/image-generation.md) and [video generation](../capabilities/generation/video-generation.md).
