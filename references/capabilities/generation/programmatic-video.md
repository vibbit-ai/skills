# Programmatic video

Use programmatic rendering for controlled charts, numbers, cards, interfaces, maps, animated typography, and full audiovisual compositions. Ground all text and data in the user's actual material.

Choose the existing project or template's real engine. [Remotion and Hyperframes](../../engines/index.md) are external official skills and project dependencies, not bundled runtimes. Simple cuts, joining, subtitles, or mixing may only need [local FFmpeg composition](../processing/local-composition.md). If installation is declined, choose an appropriate cloud/hybrid route; cloud composition does not execute local engine code.

Inspect selected template parameters instead of inventing a universal CLI. Distinguish full video, clip, and transparent overlay outputs. Preview and render the real project, inspect the final media, then return the [artifact](../../contracts/render-artifact.md). Upload only for a required downstream cloud step. See [local rendering](../../runtime/local-rendering.md).
